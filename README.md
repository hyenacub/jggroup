# 유튜브 연애 영상 댓글 초안

연애 고민을 다루는 유튜브 채널 다섯 곳의 최신 영상을 불러와, 영상마다 **그 영상 속 고민 한 줄**과
**영상 속 장면을 짚은 댓글 초안**을 보여 주고, 사용자의 유튜브 계정으로 댓글을 다는 PHP 웹 페이지.

AI(Claude Code)를 활용한 프로그램 개발 과제로 만들었다.

## 기능

1. **[영상 불러오기]** — 다섯 채널의 최신 영상을 썸네일 · 제목 · 채널 · 올린 날짜(KST)로 목록에 띄운다.
2. **영상 선택** — 영상 속 고민 한 줄과 댓글 초안, 기준 통과 여부가 나온다. 초안은 화면에서 고치고 [복사]할 수 있다.
3. **[댓글 달기]** — 레이어에서 유튜브(Google) 계정으로 로그인하고, 초안을 고치거나 새로 써서 게시한다.

여기까지 모두 사이트 회원가입 없이 쓴다. 로그인은 댓글을 다는 순간 유튜브 계정으로만 한다.

## 실행

PHP 7.0 이상(curl, mbstring, simplexml 확장)이면 된다. DB 는 쓰지 않는다.

```bash
cp .env.example .env              # 댓글 달기까지 쓰려면 YOUTUBE_OAUTH_CLIENT_ID 를 채운다
php -S localhost:8080
# 브라우저에서 http://localhost:8080/youtube_comments.php

php test_youtube.php              # 테스트 (네트워크 없이 돈다, 전부 통과하면 exit 0)
```

`YOUTUBE_OAUTH_CLIENT_ID` 가 비어 있으면 목록 · 초안 · [복사] 까지만 동작하고 [댓글 달기] 는 꺼진다.
발급 방법은 `.env.example` 주석에 있다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `youtube_comments.php` | 화면. 목록 · 상세 · 댓글 달기 레이어, 게시 엔드포인트(`POST action=post`) |
| `youtube.php` | 채널 RSS 읽기 · 캐시, 초안 기준 검사, 게시 한도, 유튜브 API 호출 |
| `youtube_drafts.php` | 영상 ID 별 고민 한 줄 · 댓글 초안 · 언급한 장면(cue) |
| `test_youtube.php` | 피드 파싱 · 초안 기준 · 게시 한도 테스트 |
| `env.php` / `compat.php` | `.env` 로더, PHP 7.0 에 없는 내장 함수 보충 |
| `assets/*.css` | 화면 스타일 |

## 설계 판단

**영상 목록은 Data API 가 아니라 채널 RSS 로 읽는다.** 키와 할당량이 필요 없다. 대신 채널당 최근 15개뿐이고
조회수 · 길이는 없다. 피드는 10분 캐시하고, [영상 불러오기]도 60초 안에는 캐시를 쓴다 — 로그인 없이 열리는
화면이라 연타가 그대로 유튜브 요청이 되면 서버 IP 가 막힌다.

**초안은 생성하지 않고 사람이 쓴다(`youtube_drafts.php`).** 자막을 읽고 그 영상에만 있는 장면 · 말을 집는다.
제목만 보고 만든 댓글은 어느 영상에 달아도 되는 뻔한 글이 되어 채널 주인 눈에 홍보로 보인다.
**초안이 없는 영상은 목록에 나오지 않는다**(자막 없는 라이브 등).

**초안 기준은 `yt_draft_problems()` 한 곳에 있다.** 화면의 통과/위반 표시, 게시 직전 검사, 테스트가 모두 이 함수를 쓴다.

- 40 ~ 120자
- 링크 금지 — `http` 가 없어도 도메인 모양이면 유튜브가 링크로 바꾸므로 같이 막는다
- 해시태그 금지 — 전각 `＃` 포함
- 특정 업체 이름 · 이용 후기처럼 읽히는 표현("봤더니", "추천합니다" 등) · 결과 장담("반드시", "100%") 금지.
  업체 이름이 들어간 시청자 댓글은 써 본 사람의 추천으로 읽히고, 지어낸 경험은 꾸민 후기다.
- 영상 속 장면 · 말(`cue`)이 초안에 글자 그대로 있어야 한다 — "구체적인 장면을 언급했다" 를 사람 눈이 아니라
  테스트로 확인하려는 칸이다. 테스트는 초안 · 장면 · 앞머리 12자가 영상마다 다른지도 본다.
- 사용자가 레이어에서 새로 쓴 글은 장면 언급만 보지 않고 나머지 기준은 그대로 적용한다.

**댓글은 사용자 본인의 유튜브 계정으로 올린다.** Google Identity Services 토큰 방식이고, 범위는 댓글 쓰기에
필요한 최소인 `youtube.force-ssl` 이다. Google 로그인 화면은 iframe 삽입이 막혀 있어 레이어의 버튼이 팝업을 띄운다.

**게시는 서버를 거친다.** 브라우저가 유튜브를 직접 부르면 한도를 서버가 지킬 수 없어서다. 브라우저가 토큰을
게시 요청 한 건에 실어 보내면 서버가 기준과 한도를 확인한 뒤 대신 올린다. 토큰은 그 요청 안에서만 쓰고
세션 · 파일 · 로그 어디에도 남기지 않는다(남의 계정으로 글을 쓸 수 있는 값이다). 브라우저 쪽도 JS 메모리에만 둔다.

**게시 한도: 영상당 1개, 하루(KST) 전체 10개.**

- 계정별이 아니라 이 화면 전체로 센다 — 계정별이면 로그인만 바꿔 우회한다.
- 기록은 `logs/youtube_posts.json`(영상 id · 댓글 id · 날짜만). 브라우저에 두면 새로고침으로 풀린다.
- 확인부터 기록까지 `flock` 으로 잠근다. 두 탭에서 동시에 누른 두 건이 나란히 한도를 통과하지 않게.
- 기록 파일을 열지 못하면 올리지 않는다(한도를 지킬 수 없으므로).
- 판정은 `yt_post_limit_problem()`(기록 배열만 받는 순수 함수)이라 테스트로 고정돼 있다.
- 기록 파일을 지우면 한도가 초기화된다.

## 알려진 제약

- http 로는 `localhost` 만 Google 로그인이 된다. LAN IP 로 연 화면에서는 로그인이 안 된다.
- 안드로이드 WebView 에서는 Google 로그인이 막힌다(`disallowed_useragent`).
- OAuth 동의 화면이 "테스트" 상태면 등록한 테스트 사용자만 로그인된다. 일반 공개에는 Google 앱 인증이 필요하다.
- 댓글 한 건은 API 할당량 50(기본 하루 10,000)을 쓴다.
- 새 영상이 올라와도 초안을 더하기 전까지는 목록에 나오지 않는다.
